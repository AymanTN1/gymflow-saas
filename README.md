## ✨ Features

- 🎨 **Premium Dark-Mode UI** — Gold-on-black gym aesthetic
- 🏗️ **3D Immersive Hero** — Three.js scene with floating gym equipment, particles
- 📊 **Interactive Dashboard** — Badge Digital, Cours, Abonnement panels
- 💳 **Pricing Section** — Happier Pack & Happy Pack with full tariff grid
- 🔌 **REST API** — Spring Boot backend serving pricing & contact data
- 🐳 **Dockerized** — One-command deployment with docker-compose

## 🚀 Quick Start

### Development

```bash
# Backend
cd backend
mvn spring-boot:run

# Frontend  
cd frontend
npm install
npm run dev
```

### Docker

```bash
docker-compose up --build
```

- Frontend: http://localhost
- Backend API: http://localhost:8080/api
